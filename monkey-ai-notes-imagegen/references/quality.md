# 验收与停止条件

打开每张结果，逐项核对用户文案。标题、产品名、数字、步骤顺序错误就不能声称通过；文件可解码不等于视觉通过。真实截图不能被重绘出虚假功能。

| 项目 | 看什么 |
|---|---|
| 比例边距 | 3:4，主体约x70–1010@1080；不同输出分辨率归一化比较 |
| 底板 | profile对应暖白、网格；排除插画和角落装饰影响 |
| 标题 | 极粗、断行、字面高度、留白；不把不同文字做全图像素差 |
| 组件 | 黑描边、统一圆角、无模糊偏移影；只比较同类组件 |
| 配色 | 一个主色统领内容页，漫画内部允许多色 |
| 构图 | 上判断、中证据、下结论；按语义选布局 |
| 插画 | 默认2D检查墨线、表情与暖光；early storybook-3d检查柔光、毛发和立体童话材质 |
| 可读性 | 手机宽约360时能读主标题，小脚注不承担关键事实 |

`inspect_image.py image.png --reference REF --out qa.json`需Pillow与numpy，只读图。颜色和网格估计是诊断，不是美学评分；四角装饰、压缩和文字会污染估计。顶部竖线周期不等于已证明整个画布是方格。脚本不判断中文错字、字重和具体描边宽度。

以下人工标注后的工程容差仅适用于editorial-bold普通卡片；其它profile/组件以其token为中心采用相应容差，不套用这些绝对值：普通描边7±1、阴影12/14±3、边距70±6、网格82±4、平色RGB每通道约±8。它们是复用规范，不是201图统计分位，不是模型硬保证。未测量不能声称这些像素项全部通过。

禁止报告没有定义的「98%还原度」；不同主题全图MAE/SSIM不能证明同风格。保存实际工具/宽高/参考/prompt/修正/文案核对和剩余偏差。最多两次定向修正；仍有关键错字要明确未完成项。
