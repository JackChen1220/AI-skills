# Speak Replay 教材场景学习包

适用于 Speak Replay 素材制作，或用户要求复用已验证的教材单词闪卡方法。此配置补充通用流程，不把某一册的词数、人物发型、绝对目录或上线状态固化为所有任务的要求。

## 交付与封面

- 默认使用 `app_bundle`：场景底图、词汇、学习内容、位置样式独立；确定性叠层图供检查，产品运行时读取数据。
- 课程底图及课程封面默认9:16、1080×1920。请求原生竖构图，保留 `base-native.png`；正式尺寸只允许比例误差范围内的等比归一化/像素取整，不把横图硬裁或拉伸成竖图。
- 课程 `cover.png` 默认逐字节复用纯底图 `base.png`，不再为每课另生横封面。
- **专辑封面独立配置**：先读当前用户要求、专辑元数据和相关交接。可以有单独横版专辑封面；不要把课程9:16规则套到专辑封面，也不要因为专辑横封面而改课程竖封面。没有单独要求时可复用课程竖底图。
- 制作素材不自动授权导入、发布或修改功能源码/数据库。按本次范围输出交接；后续状态读当前项目记录，不把历史“未发布”或“已发布”当常量。

## 来源与分组

1. 联合读取教材PDF/词表图片与Excel/CSV：保留原始字段、来源页/行、文件指纹，建立稳定词条ID。教材义项优先；若用户指定其他事实源则遵从用户。
2. 对比两份来源的数量和身份；英美拼写、同形异义、跨单元重复词保留独立来源身份，不用简单字符串去重。每个身份恰好分配一次或明确记录暂缓原因。
3. 教材疑误先看原页确认。确需教学校正时保留原值、校正值、原因及可靠依据，不静默覆盖。教材只给词组中某个词的IPA时，整词组教学IPA置空，保留原组件；不靠猜测补全音标。
4. 按同一自然场景或行动链分组，通常3–5词，可因教学机制用1–6词。高中抽象词可通过讨论、研究、判断等真实活动与例句学习，不为凑齐词数堆砌道具。

## 人物与场景

从本批次已接受的图建立人物参考与简短特征记录，后续生成引用同一参考；保持脸型、发型、年龄及服装逻辑一致。小学使用适龄儿童画风，高中使用适龄学生与成人形象；不把儿童模板机械套到高中。

以场景中的交流和动作为主体，给词卡预留角落及上下空白。照片/展板中的一般历史人物不冒认具体名人；抽象概念依靠语言语境，不把不相干物体标成目标概念。

本配置为**无连线情境词卡**：每词仍在 SceneBrief 中记录 mapping mode；连接线策略设为 `none` 并记录 profile。不得为了迁就指物连线而把抽象词硬连向人脸或道具。通用指物卡的连接线默认不受本配置影响。

## 数据与渲染边界

建议沿用当前项目已有文件名；下面是已验证的职责划分，不是另造一套产品API：

| 文件 | 职责 |
| --- | --- |
| `vocabulary_master.json` / `card_plan.json` | 全量来源身份与唯一分组 |
| `metadata.json` | 课程ID、标题、资源引用、实际状态 |
| `base-native.png` / `base.png` | 原生生成图与正式纯底图 |
| `cover.png` / `cover_asset.json` | 课程竖封面与复用指纹/来源 |
| `vocabulary.json` | 本课英文、完整IPA或null、教材义项及稳定ID |
| `learning.json` | 词汇、原创例句译文、练习与产品需要的分层scene |
| `layout_spec.json` | `wordId`、归一化box、顺序及样式；不复制term/IPA/中文 |
| `compiled_prompt.json` / `base_asset.json` | 实际提示、参考图、模型来源、尺寸和指纹 |
| `qa.json` / manifest / progress | 当前版本检查证据、产出数与发布数 |

`learning.words` 与 vocabulary 按稳定ID及文本一致。每词至少一个自然例句和准确译文；教材展示中的sb/sth在例句里自然展开。配置场景理解、逐词练习、覆盖本课所有词的迁移表达；只有确有教学价值时加短对话，不机械堆练习。

先读目标项目当前学习数据Schema，再生成或适配内容；运行它的真实校验器，避免复制旧Schema宣称兼容。Skill的通用Schema不是产品 `learning.json`/metadata的替代品。旧版layout中的term字段仅作兼容，新版使用wordId引用。

底图不烘焙教学英文、IPA、中文释义、词卡、连线或品牌。渲染时从独立数据精确排版，校验归一化坐标不越界、不相互遮挡，字体覆盖IPA及中文。学习页品牌按当前 Speak Replay 品牌规范叠加：纯文字字标，Replay下方 `#BBFF2B` 绿线，无前置图标；不把Grace视频封面的特例套到本课程底图。

审阅页可以提供中文/整层词卡开关帮助检查；它们是审阅工具，不自动成为正式产品功能。正式学习页交互以当前产品契约和用户要求为准。

## 批量执行与适度QA

- 先完成来源核对、全册分组、数据与布局，再按卡生成；每次图片调用只产一张完整底图，不生成拼贴或联系表冒充多张成品。可并发独立工具调用，但不默认创建子Agent。
- OpenAI环境使用当前可用的原生图像生成/编辑工具。保留成功输出和实际错误；相同网络失败有限重试（默认最多再试两次），仍失败则保留pending并处理可独立推进的工作，不换未经授权的CLI/API，不伪造成功。
- 正式检查包括：来源覆盖与数据一致、场景及人物主体、实际底图和叠层可读性、脸手/关键动作遮挡、尺寸及资源指纹。审阅板可合并展示底图/叠层/必要局部，避免反复翻看相同全图；仅在有具体疑点时放大局部。
- **完成优先于无收益的细修**：错词、误导场景、目标缺失、明显遮挡或风格大幅漂移必须修。普通微小纹理、缝线、非教学纸面底纹不自动触发重生；在用户允许的范围记 `WARN` 及接受原因。不能把教学伪字或误导标识当“微细节”放过，也不能把未看过的图标成视觉通过。
- 先移动词卡或修数据；只有底图本身妨碍学习时才编辑/重生底图。疑似瑕疵先确认，不因一个微小疑点连续返修。通过必要检查后停止该卡返修，继续出齐余卡。
- QA绑定base/cover/vocabulary/learning/layout的当前SHA256及审阅证据，`humanReviewed=false`表示Agent审阅。重生成或改动数据/布局后撤销旧ready，重做受影响检查；不因存在同名旧图片就判新调用成功。
- planned、generated、ready、published分别记数。只有全量覆盖、学习数据和必要视觉检查完成后才设complete；发布数以实际读回为准。接着制作时先读进度/manifest，不重跑初始化脚本覆盖已有成品。

## 收尾

运行一次与变更相称的数据/真实Schema/尺寸/哈希检查，刷新本地预览并保存实际验证记录。交接说明封面政策、资源职责、事实源及例外、当前状态与导入范围。必要检查通过后，不因临近收尾再开展新一轮细节美化。
